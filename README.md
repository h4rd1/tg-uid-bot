# tg-uid-bot

Telegram бот для отображения UID пользователей.

## Описание

Этот бот позволяет получать уникальный идентификатор (UID) любого пользователя Telegram простым способом. Бот полезен администраторам групп и каналов для быстрого сбора необходимой информации о пользователях.

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/h4rd1/tg-uid-bot.git
   ```

2. Перейдите в каталог проекта:
   ```bash
   cd tg-uid-bot
   ```

3. Создайте файл `.env` и заполните его необходимыми параметрами:
   ```bash
   nano .env # замените YOUR_TELEGRAM_BOT_TOKEN на ваш токен бота
   ```

4. Запустите контейнер Docker:
   ```bash
   docker-compose up
   ```

## Использование

Просто отправьте команду `/start`, чтобы начать работу с ботом. Для получения UID конкретного пользователя, упомяните его в чате, добавив символ `@`.
